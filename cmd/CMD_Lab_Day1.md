# מעבדת CMD - יום 1 (Windows)

## רקע קצר
במעבדה הזו התלמידים ילמדו לעבוד עם ממשק שורת הפקודה של Windows (`CMD`) מהבסיס: ניווט בתיקיות, יצירה וניהול קבצים, עבודה עם פלט פקודות, וחילוץ מידע בסיסי מהמערכת.

המעבדה מיועדת לתלמידים ללא ניסיון קודם.

---

## מטרות למידה
- להכיר את סביבת `CMD` ולהרגיש בנוח לעבוד ללא ממשק גרפי.
- להבין ניווט בין תיקיות ושימוש בנתיבים.
- לבצע פעולות קובץ/תיקיה נפוצות דרך פקודות.
- להשתמש בהפניית פלט (`>`, `>>`) ובחיפוש טקסט בסיסי (`findstr`).
- לבצע משימת סיכום המדמה תרחיש עבודה "האקרי" פשוט.

---

## דרישות מוקדמות
- מחשב Windows עם גישה ל-`Command Prompt`.
- הרשאות משתמש רגיל מספיקות לרוב המשימות.
- מומלץ לעבוד בתיקיית תרגול יעודית בלבד.

---

## חוקי מעבדה
1. עובדים רק בתוך תיקיית התרגול, לא מוחקים קבצים מחוץ אליה.
2. אחרי כל שלב - צילום מסך של הפקודות והתוצאה.
3. אם פקודה לא עובדת: לבדוק שגיאות כתיב, רווחים, ונתיב.
4. לא מעתיקים פתרון בלי לכתוב מה כל פקודה עושה.

---

## הכנה ראשונית (5 דקות)
פתחו `CMD` והקלידו:

```bat
echo %USERNAME%
hostname
ver
```

צרו תיקיית עבודה:

```bat
cd %USERPROFILE%\Desktop
mkdir CMD_LAB
cd CMD_LAB
```

בדיקה:

```bat
cd
dir
```

## שלב 1 - היכרות עם פקודות בסיס (10 דקות)
### משימות
1. נקו את המסך עם `cls`.
2. הריצו `help` ועיינו ברשימת הפקודות.
3. הריצו `help dir` וכתבו במשפט מה הפקודה `dir` עושה.
4. הריצו `date /t` ו-`time /t`.
5. שמרו את פלט `help` לקובץ בשם `help_output.txt`.

### רמז
להפניית פלט לקובץ:

```bat
help > help_output.txt
```

## שלב 2 - ניווט במערכת קבצים (15 דקות)
### משימות
1. צרו את מבנה התיקיות הבא:

```text
CMD_LAB
|-- Day1
|   |-- Notes
|   |-- Tasks
|-- Temp
```

2. עברו לתיקיית `Notes` בעזרת `cd`.
3. חזרו תיקיה אחת אחורה בעזרת `cd ..`.
4. עברו ישירות ל-`Tasks` עם נתיב מלא.
5. הציגו את עץ התיקיות עם `tree`.

### פקודות אפשריות
```bat
mkdir Day1 Day1\Notes Day1\Tasks Temp
cd Day1\Notes
cd ..
tree
```

## שלב 3 - עבודה עם קבצים (20 דקות)
### משימות
1. בתוך `Day1\Tasks`, צרו קובץ `todo.txt`.
2. הוסיפו לקובץ 3 שורות משימות עם `echo` והפניה (`>` ואז `>>`).
3. הציגו את תוכן הקובץ עם `type`.
4. העתיקו את הקובץ ל-`todo_backup.txt`.
5. שנו שם ל-`todo_day1.txt`.
6. העבירו את קובץ הגיבוי לתיקיית `Temp`.

### דוגמה
```bat
echo משימה 1: ללמוד dir > todo.txt
echo משימה 2: ללמוד cd >> todo.txt
echo משימה 3: ללמוד copy >> todo.txt
type todo.txt
copy todo.txt todo_backup.txt
ren todo.txt todo_day1.txt
move todo_backup.txt ..\..\Temp
```

## שלב 4 - חיפוש ומיון מידע (15 דקות)
### משימות
1. צרו קובץ `events.log` עם לפחות 8 שורות, שחלקן כוללות את המילה `ERROR` וחלקן `INFO`.
2. הציגו רק שורות `ERROR` בעזרת `findstr`.
3. שמרו את שורות `ERROR` לקובץ `errors_only.log`.
4. מיינו את `errors_only.log` ושמרו ל-`errors_sorted.log`.

### דוגמה
```bat
findstr ERROR events.log
findstr ERROR events.log > errors_only.log
sort errors_only.log > errors_sorted.log
```

## שלב 5 - מידע מערכת בסיסי (10 דקות)
### משימות
1. שמרו את פלט `ipconfig` לקובץ `network.txt`.
2. שמרו את פלט `tasklist` לקובץ `tasks.txt`.
3. שמרו את שם המשתמש ותחנת העבודה לקובץ `identity.txt`.

### דוגמה
```bat
ipconfig > network.txt
tasklist > tasks.txt
echo User: %USERNAME% > identity.txt
echo Host: %COMPUTERNAME% >> identity.txt
```

## שלב 6 - מיני אתגר מסכם (20 דקות)
### תרחיש
אתם "אנליסטים" שצריכים להכין תיקיית דוח חקירה מסודרת.

### משימות
1. צרו תיקיה בשם `Report`.
2. העבירו אליה את:
   - `errors_sorted.log`
   - `network.txt`
   - `identity.txt`
3. צרו קובץ `summary.txt` עם 4 שורות:
   - שם תלמיד
   - תאריך
   - כמה שורות `ERROR` נמצאו
   - הערה אישית קצרה
4. הציגו `dir Report` כדי לוודא שהכל קיים.

### טיפ לספירת שורות
אפשר להשתמש ב:
```bat
find /c /v "" errors_sorted.log
```

## הרחבה לשיעור הבא
### 1) היכרות עם משתני סביבה (`set`, `%PATH%`)
**מטרה:** להבין מה זה משתנה סביבה ואיך משתמשים בו.

**הדגמה קצרה ב-CMD:**
```bat
set
echo %USERNAME%
echo %PATH%
set CLASS=IT_Beginners
echo %CLASS%
set CLASS=
echo %CLASS%
```

**הסבר לתלמידים:**
- `set` מציג את כל משתני הסביבה הקיימים.
- `%USERNAME%` ו-`%PATH%` הם משתנים מובנים של המערכת.
- `set CLASS=...` יוצר/מעדכן משתנה זמני לחלון CMD הנוכחי.
- `set CLASS=` מוחק את המשתנה מהסשן הנוכחי.

---

### 2) לולאות בסיס ב-`batch`
**מטרה:** להריץ פעולה שחוזרת על עצמה בלי לכתוב את אותה פקודה שוב.

**צרו קובץ בשם `loop_demo.bat`:**
```bat
@echo off
echo === הדגמת לולאה פשוטה ===
for %%i in (1 2 3 4 5) do echo מספר: %%i
pause
```

**להרצה:**
```bat
loop_demo.bat
```

**מה התלמידים יראו:** הדפסה של המספרים 1 עד 5, כל פעם באיטרציה חדשה.

---

### 3) תנאים וקבצי `.bat` מתקדמים
**מטרה:** לבצע החלטה לפי קלט של משתמש.

**צרו קובץ בשם `if_demo.bat`:**
```bat
@echo off
set /p name=הכנס שם משתמש:
if /I "%name%"=="admin" (
    echo שלום מנהל מערכת!
) else (
    echo שלום %name%, אין לך הרשאות admin.
)
pause
```

**נקודות לימוד חשובות:**
- `set /p` מקבל קלט מהמשתמש.
- `if` בודק תנאי.
- `/I` אומר להשוות בלי רגישות לאותיות גדולות/קטנות.
- הבלוקים `(` `)` מאפשרים כמה פקודות תחת אותו תנאי.
