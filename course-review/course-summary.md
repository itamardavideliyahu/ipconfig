# סיכום הקורס — תקשורת מחשבים ומערכות הפעלה

> סיכום קצר לכל נושא לפי סדר הסילבוס. מיועד לחזרה לפני בוחן.

---

## חלק א — מבואות ותשתית

### הכרת המחשב | מבוא לחומרה | מבוא לתוכנה

המחשב בנוי משני עולמות:

| סוג | מה זה | דוגמאות |
|-----|--------|---------|
| **חומרה (Hardware)** | הרכיבים הפיזיים | מעבד (CPU), זיכרון RAM, דיסק, כרטיס רשת |
| **תוכנה (Software)** | הוראות ותוכניות | מערכת הפעלה, דפדפן, Word |

רכיבי ליבה של המחשב:
- **CPU** — מבצע חישובים, "המוח".
- **RAM** — זיכרון זמני; נמחק כשמכבים.
- **Storage (HDD/SSD)** — זיכרון קבוע לאחסון קבצים.
- **GPU** — עיבוד גרפי.
- **NIC** — כרטיס רשת, מחבר למינטרנט.
- **Motherboard** — לוח האם, מחבר הכל יחד.

---

### מבוא לוירטואליזציה | הקמת מכונה וירטואלית | הקמת מעבדה וירטואלית

**וירטואליזציה** = הרצת מחשב שלם בתוך מחשב, כתוכנה.

```
[מחשב פיזי]
    └── [Hypervisor (VirtualBox / VMware)]
            ├── [מכונה וירטואלית A — Windows]
            └── [מכונה וירטואלית B — Linux]
```

| מושג | הסבר |
|------|------|
| **Hypervisor** | התוכנה שמנהלת את המכונות הוירטואליות |
| **VM (Virtual Machine)** | מחשב מלא בתוך קובץ |
| **Snapshot** | "תמונת מצב" — אפשר לחזור אליה אם משהו נשבר |
| **Guest OS** | מערכת ההפעלה שרצה בתוך ה-VM |
| **Host OS** | מערכת ההפעלה של המחשב הפיזי |

**יתרונות:** חיסכון בחומרה, בידוד, קלות לשחזור, סביבת מעבדה בטוחה.

## חלק ב — מערכת ההפעלה Windows

### מבנה מערכת ההפעלה Windows | מבוא ל-Windows

**מערכת ההפעלה (OS)** היא הגשר בין המשתמש לחומרה.

שכבות Windows:

```
[משתמש]
    ↕
[אפליקציות — דפדפן, Word...]
    ↕
[Windows API]
    ↕
[Kernel — ליבת המערכת]
    ↕
[חומרה — CPU, RAM, דיסק]
```

| רכיב | תפקיד |
|------|--------|
| **Kernel** | ניהול משאבים ותיאום בין תוכנה לחומרה |
| **File System (NTFS)** | ארגון קבצים בדיסק |
| **Task Manager** | ניהול תהליכים ומשאבים |
| **Registry** | מסד נתוני הגדרות המערכת |

---

### ה-Registry

**Registry** = מסד נתונים מרכזי שבו Windows מאחסן **את כל הגדרות המערכת**.

כיצד לפתוח: `Win + R` → `regedit`

```
HKEY_LOCAL_MACHINE (HKLM)   ← הגדרות מחשב
HKEY_CURRENT_USER (HKCU)    ← הגדרות משתמש נוכחי
HKEY_CLASSES_ROOT           ← סיומות קבצים ותוכניות
HKEY_USERS                  ← כל המשתמשים
HKEY_CURRENT_CONFIG         ← הגדרות חומרה נוכחיות
```

> **אזהרה:** שינויים שגויים ב-Registry עלולים לשבור את המערכת — תמיד גיבוי לפני שינוי!

---

### תהליכים | ביצועים | לוגים | שירותי מערכת

**תהליך (Process)** = תוכנית שרצה בזיכרון. לכל תהליך יש PID ייחודי.

| כלי | תפקיד | פתיחה |
|-----|--------|--------|
| **Task Manager** | ראיית תהליכים וצריכת משאבים | `Ctrl + Shift + Esc` |
| **Event Viewer** | יומן אירועים — שגיאות, אזהרות, מידע | `eventvwr` |
| **Services** | ניהול שירותי מערכת (הפעלה/עצירה) | `services.msc` |
| **Performance Monitor** | ניטור ביצועים לאורך זמן | `perfmon` |

**לוגים (Logs)** = יומן מה קרה במערכת. קריטי לאבחון תקלות.  
סוגי לוגים ב-Event Viewer: `System`, `Application`, `Security`.

**שירותי מערכת (Services)** = תוכניות שרצות ברקע בלי ממשק משתמש.  
דוגמאות: `Print Spooler`, `Windows Update`, `DNS Client`.

## חלק ג — ממשק פקודות (CLI)

### מבוא לממשק פקודות CLI | פקודות מתקדמות

**CLI (Command Line Interface)** = שליטה במחשב דרך הקלדת פקודות (ללא עכבר).

**פקודות CMD בסיסיות:**

| פקודה | תפקיד | דוגמה |
|-------|--------|--------|
| `dir` | הצג תוכן תיקייה | `dir C:\` |
| `cd` | מעבר לתיקייה | `cd Desktop` |
| `mkdir` | יצירת תיקייה | `mkdir MyFolder` |
| `copy` | העתקת קובץ | `copy a.txt b.txt` |
| `del` | מחיקת קובץ | `del file.txt` |
| `cls` | ניקוי מסך | `cls` |
| `ipconfig` | הגדרות רשת | `ipconfig /all` |
| `ping` | בדיקת חיבור | `ping 8.8.8.8` |
| `tasklist` | רשימת תהליכים | `tasklist` |
| `sc query` | סטטוס שירות | `sc query wuauserv` |

**הפניית פלט:**
```bat
dir > output.txt        ← שמור לקובץ (מחק קיים)
dir >> output.txt       ← הוסף לקובץ
dir | findstr ".txt"    ← סינון תוצאות
```

---

### מבוא לקבצי Batch

**קובץ Batch (.bat)** = רצף פקודות CMD שנשמר בקובץ ומורץ יחד.

```bat
@echo off
echo Starting script...
mkdir C:\MyBackup
copy C:\Data\* C:\MyBackup\
echo Done!
pause
```

| שורה | משמעות |
|------|--------|
| `@echo off` | לא להציג כל פקודה על המסך |
| `echo` | הדפסת טקסט |
| `pause` | המתן ללחיצת מקש |
| `%VAR%` | שימוש במשתנה |
| `if` / `for` | תנאים ולולאות |

**שימושים נפוצים:** גיבויים אוטומטיים, התקנות, תחזוקה שוטפת.

## חלק ד — PowerShell

### מבוא ל-PowerShell

**PowerShell** = שפת סקריפטינג מתקדמת של Microsoft — **חזקה בהרבה מ-CMD**.

ההבדל המרכזי: CMD עובד עם **טקסט**, PowerShell עובד עם **אובייקטים**.

**פקודות PS בסיסיות (Cmdlets):**

| פקודה | תפקיד | מקבילה ב-CMD |
|-------|--------|-------------|
| `Get-ChildItem` | רשימת קבצים | `dir` |
| `Set-Location` | מעבר תיקייה | `cd` |
| `New-Item` | יצירת קובץ/תיקייה | `mkdir` / `type` |
| `Copy-Item` | העתקה | `copy` |
| `Remove-Item` | מחיקה | `del` |
| `Get-Process` | רשימת תהליכים | `tasklist` |
| `Stop-Process` | סגירת תהליך | `taskkill` |
| `Get-Service` | שירותי מערכת | `sc query` |

**Pipeline — סינון ועיבוד:**
```powershell
Get-Process | Where-Object {$_.CPU -gt 100} | Sort-Object CPU
Get-Service | Where-Object {$_.Status -eq "Stopped"}
```

## חלק ו — תקשורת מחשבים

### מבוא לתקשורת מחשבים | מבוא לציוד רשת

**רשת מחשבים** = חיבור של שני מחשבים או יותר כדי לשתף משאבים ומידע.

| סוג רשת | טווח | דוגמה |
|---------|------|--------|
| **LAN** | חדר / בניין | רשת בית / משרד |
| **WAN** | מדינות / יבשות | האינטרנט |
| **WLAN** | Wi-Fi | רשת אלחוטית |

---

### מודל OSI — 7 שכבות

מודל תיאורטי שמחלק את תהליך התקשורת ל-7 שכבות:

| שכבה | שם | תפקיד | דוגמת פרוטוקול |
|------|-----|--------|---------------|
| 7 | **Application** | ממשק משתמש | HTTP, DNS, FTP |
| 6 | **Presentation** | קידוד ודחיסה | TLS, JPEG |
| 5 | **Session** | ניהול חיבורים | NetBIOS |
| 4 | **Transport** | אמינות + פורטים | TCP, UDP |
| 3 | **Network** | ניתוב בין רשתות | IP, ICMP |
| 2 | **Data Link** | כתובות MAC | Ethernet, ARP |
| 1 | **Physical** | סיגנל פיזי | כבל, Wi-Fi |

> **טיפ לזכירה:** "All People Seem To Need Data Processing" (מ-7 ל-1)

---

### מודל TCP/IP — 4 שכבות

המודל **המעשי** שעליו בנוי האינטרנט:

| שכבת TCP/IP | מקביל ל-OSI | פרוטוקולים |
|------------|------------|------------|
| **Application** | 5+6+7 | HTTP, DNS, DHCP, SSH |
| **Transport** | 4 | TCP, UDP |
| **Internet** | 3 | IP, ICMP, ARP |
| **Network Access** | 1+2 | Ethernet, Wi-Fi |

---

### תהליך הכימוס — Encapsulation

כשנתונים יוצאים מהמחשב, כל שכבה **עוטפת** (מוסיפה header) לנתונים שמתחתיה:

```
[DATA]
[TCP Header | DATA]                  ← Layer 4 מוסיף
[IP Header | TCP Header | DATA]      ← Layer 3 מוסיף
[ETH Header | IP | TCP | DATA | FCS] ← Layer 2 מוסיף
```

בצד המקבל — התהליך הפוך: כל שכבה **מסירה** את ה-header שלה.

### מבוא לכתובות IP | Public & Private IP

| סוג | טווח | מי מקצה | נראה מבחוץ? |
|-----|------|---------|------------|
| **Public IP** | כל שאר הכתובות | ISP | כן |
| **Private IP** | `10.x.x.x` / `172.16-31.x.x` / `192.168.x.x` | Router/DHCP | לא |

**Subnet Mask** — מגדיר מה חלק הרשת ומה חלק המכשיר:
```
IP:          192.168.1.10
Subnet:      255.255.255.0  (= /24)
רשת:         192.168.1.___
מכשיר:                  .10
```

---

### הנתב (Router) | המתג (Switch) | ניתוב תעבורה

| רכיב | שכבה | תפקיד | מזהה לפי |
|------|------|--------|---------|
| **Switch** | Layer 2 | מחבר מכשירים **בתוך** הרשת | MAC Address |
| **Router** | Layer 3 | מחבר **בין** רשתות (LAN ↔ WAN) | IP Address |

**Router — תפקידים מרכזיים:**
- **ניתוב** — מחליט לאן לשלוח כל חבילה לפי Routing Table
- **DHCP** — מחלק IP אוטומטית
- **NAT** — מתרגם IP פנימי ↔ ציבורי
- **Firewall** — חוסם/מאפשר תעבורה

**NAT (Network Address Translation) — דוגמה:**

```
PC-1: 192.168.1.10:52341  ──►  Router NAT  ──►  82.166.10.5:52400  ──►  google.com
                                  ↑
                          שומר בטבלה: מי שלח, מאיזה פורט
```

---

### מבוא לפרוטוקולי תקשורת ו-RFC

**פרוטוקול** = הסכם מוגדר בין שני צדדים כיצד לתקשר.  
**RFC (Request for Comments)** = מסמך רשמי שמגדיר פרוטוקול. מפורסם על ידי IETF.

דוגמאות: RFC 791 = IP, RFC 793 = TCP, RFC 1035 = DNS.

---

### מבוא לפרוטוקול UDP

**UDP (User Datagram Protocol)** — פרוטוקול Layer 4, **מהיר אך לא אמין**.

| מאפיין | UDP |
|--------|-----|
| חיבור? | לא — Connectionless |
| אמינות? | לא — אין אישור קבלה |
| סדר? | לא מובטח |
| מהירות | גבוהה |
| שימושים | DNS, DHCP, Streaming, Gaming |

---

### מבוא לפרוטוקול TCP

**TCP (Transmission Control Protocol)** — Layer 4, **אמין אך איטי יותר**.

**3-Way Handshake:**
```
Client          Server
  │── SYN ──────►│   "רוצה להתחבר"
  │◄── SYN-ACK ──│   "אשרתי"
  │── ACK ──────►│   "מחובר"
```

| מאפיין | TCP |
|--------|-----|
| חיבור? | כן — Connection-oriented |
| אמינות? | כן — ACK לכל חבילה |
| סדר? | מובטח |
| מהירות | נמוכה מ-UDP |
| שימושים | HTTP/S, SSH, FTP, Email |

---

### מבוא לפרוטוקול DNS

**DNS** = "ספר הטלפונים של האינטרנט" — ממיר שמות לכתובות IP.

```
אתה כותב: google.com
    ↓
DNS Query → שרת DNS
    ↓
DNS Response: 142.250.185.78
    ↓
הדפדפן מתחבר ל-IP
```

| רשומת DNS | תפקיד | דוגמה |
|-----------|--------|--------|
| **A** | שם → IPv4 | `google.com → 142.250.185.78` |
| **AAAA** | שם → IPv6 | |
| **MX** | שרת דואר | |
| **CNAME** | כינוי לשם אחר | `www → example.com` |

**פורט:** UDP 53 (שאילתות) / TCP 53 (תשובות גדולות).

---

### מבוא לפרוטוקול DHCP

**DHCP** = מחלק כתובות IP **אוטומטית** — תהליך DORA:

```
Client ── DISCOVER ──────────────► Server   "מישהו פה?"
Client ◄───────────────── OFFER ── Server   "קח IP: .25"
Client ── REQUEST ───────────────► Server   "אני לוקח"
Client ◄─────────────────── ACK ── Server   "מאושר!"
```

---

### מבוא לפרוטוקול HTTP

**HTTP (HyperText Transfer Protocol)** = פרוטוקול גלישה, Layer 7, פורט **80**.  
**HTTPS** = HTTP + הצפנת TLS, פורט **443**.

```
Client → GET /index.html HTTP/1.1 → Server
Client ← HTTP/1.1 200 OK ← Server
```

| קוד | משמעות | דוגמה |
|-----|--------|--------|
| **200** | הצלחה | הדף נטען |
| **301/302** | הפניה | http → https |
| **404** | לא נמצא | דף לא קיים |
| **500** | שגיאת שרת | תקלה בצד שרת |

---

### מהדלקת המחשב ועד עליית אתר

תהליך מלא — מרגע לחיצת Power:

```
1. POST (Power-On Self Test) — בדיקת חומרה
2. BIOS/UEFI — טעינת הגדרות, זיהוי דיסק אתחול
3. Bootloader — טעינת ה-OS
4. Kernel נטען — ניהול חומרה
5. שירותים ותהליכי מערכת עולים
6. כניסת משתמש
        ↓
7. פתיחת דפדפן → www.google.com
8. DNS Query → קבלת IP
9. TCP Handshake לשרת גוגל
10. HTTP GET בקשה
11. TLS Handshake (HTTPS)
12. קבלת תשובת HTML ← הדף נטען
```

---

### מבוא לתוכנת Wireshark | ניתוח תעבורת רשת

**Wireshark** = כלי ניתוח תעבורה (Packet Sniffer) בקוד פתוח.

**פרוטוקולים עיקריים ופילטרים:**

| פרוטוקול | שכבה | פילטר מהיר | מה רואים |
|----------|------|------------|---------|
| **ARP** | L2 | `arp` | מי מחזיק איזה MAC |
| **ICMP** | L3 | `icmp` | בקשות/תשובות ping |
| **DNS** | L7 | `dns` | שאילתות שם → IP |
| **TCP** | L4 | `tcp` | Handshake, חיבורים |
| **HTTP** | L7 | `http` | בקשות/תשובות בטקסט ברור |
| **TLS** | L7 | `tls` | חיבורים מוצפנים |
| **DHCP** | L7 | `dhcp` | חלוקת כתובות IP |

**פילטרים שימושיים:**
```wireshark
ip.addr == 192.168.1.10        ← תעבורה מ/אל IP מסוים
tcp.port == 443                ← HTTPS בלבד
dns and ip.dst == 8.8.8.8      ← DNS ל-Google
tcp.flags.syn == 1             ← תחילת חיבורים
tcp.analysis.retransmission    ← בעיות רשת
```

## חלק ז — מערכת ההפעלה Linux

### מבנה מערכת ההפעלה Linux | היסטוריה וגרסאות

**Linux** = מערכת הפעלה בקוד פתוח, חינמית, נפוצה בשרתים ומכשירי רשת.

**הפצות נפוצות:** Ubuntu, Debian, CentOS, Kali Linux, Fedora.

```
[משתמש]
    ↕ (Shell — Bash/Zsh)
[אפליקציות]
    ↕
[Linux Kernel]
    ↕
[חומרה]
```

**מבנה תיקיות:**
```
/           ← שורש (root) — כמו C:\ ב-Windows
├── /etc    ← קבצי הגדרות מערכת
├── /home   ← תיקיות בית של משתמשים
├── /var    ← לוגים ונתונים משתנים
├── /bin    ← פקודות בסיסיות
├── /usr    ← תוכניות משתמש
└── /tmp    ← קבצים זמניים
```

---

### ה-Shell | טרמינל ו-Shell

**Shell** = ממשק שורת הפקודה של Linux.  
**Bash** (Bourne Again Shell) = ה-Shell הנפוץ ביותר.

פקודות ניווט בסיסיות:

| פקודה | תפקיד | מקבילה Windows |
|-------|--------|--------------|
| `pwd` | הצג נתיב נוכחי | `cd` (ללא ארגומנט) |
| `ls` | רשימת קבצים | `dir` |
| `ls -la` | רשימה מפורטת כולל נסתרים | `dir /a` |
| `cd` | מעבר תיקייה | `cd` |

### ניהול הרשאות בלינוקס

כל קובץ/תיקייה ב-Linux יש לו **הרשאות** לשלושה גורמים:

```
-rwxr-xr-- 1 alice dev 1024 Jul 8 file.sh
 │││││││
 │││││└─ Other (r--)  ← שאר המשתמשים
 │││└──  Group (r-x)  ← קבוצת הבעלים
 │└────  Owner (rwx)  ← הבעלים
 └─────  סוג (- קובץ, d תיקייה)
```

| סמל | ערך | משמעות |
|-----|-----|--------|
| `r` | 4 | קריאה |
| `w` | 2 | כתיבה |
| `x` | 1 | הרצה |
| `-` | 0 | ללא הרשאה |

**שינוי הרשאות:**
```bash
chmod 755 file.sh     ← rwxr-xr-x
chmod +x script.sh    ← הוסף הרשאת הרצה
chmod -w file.txt     ← הסר כתיבה
chown user:group file ← שינוי בעלות
```
