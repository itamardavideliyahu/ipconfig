### חלק א — מבואות וחומרה

**תשובה 1**  
- **RAM** — זיכרון זמני, מהיר מאוד, נמחק כשמכבים.  
- **HDD / SSD** — זיכרון קבוע, שומר נתונים לצמיתות. SSD מהיר יותר מ-HDD.

**תשובה 2**  
- **Hypervisor** = התוכנה שמנהלת את המכונות הוירטואליות (למשל VirtualBox, VMware).  
- **Guest OS** = מערכת ההפעלה שרצה **בתוך** ה-VM (למשל Windows שרץ בתוך Linux).

**תשובה 3**  
Snapshot שומר את **מצב המכונה** ברגע מסוים — אפשר לחזור אליו אם משהו נשבר או אם ניסוי נכשל.

**תשובה 4**  
מערכת ההפעלה היא התוכנה שמנהלת את כל משאבי המחשב (CPU, RAM, דיסק) ומספקת לאפליקציות ממשק לעבוד עם החומרה.

**תשובה 5**  
`regedit` (דרך `Win + R`). ה-Registry מאחסן את כל **הגדרות המערכת**: הגדרות חומרה, תוכנות, משתמשים, ומפתחות הפעלה.

### חלק ב — Windows: CLI, Batch, PowerShell

**תשובה 6**  
- `>` — כותב לקובץ ו**מוחק** את תוכנו אם כבר קיים.  
- `>>` — **מוסיף** לסוף הקובץ מבלי למחוק.

**תשובה 7**

**תשובה 8**  
`@echo off` מונע מ-CMD להדפיס כל שורת פקודה על המסך בזמן הרצת הסקריפט — הפלט יהיה נקי יותר.

**תשובה 9**  
CMD עובד עם **טקסט** — הפלט הוא מחרוזות. PowerShell עובד עם **אובייקטים** — ניתן לסנן, למיין ולגשת לשדות ספציפיים.

**תשובה 10**

Get-Service | Where-Object { $_.Status -eq "Stopped" }

### חלק ג — תקשורת מחשבים

**תשובה 12**  
**Private IP** — הטווח `192.168.x.x` שמור לכתובות פנימיות. אינו ניתן לניתוב באינטרנט.

**תשובה 13**  
Subnet Mask מגדיר איזה חלק של כתובת ה-IP מייצג **את הרשת** ואיזה חלק מייצג **את המכשיר**.  
דוגמה: `255.255.255.0` — 24 ביטים לרשת, 8 ביטים למכשיר → עד 254 מכשירים בסאבנט.

**תשובה 14**  
- **Switch** — Layer 2, מחליט לפי **MAC Address**, מחבר מכשירים **בתוך** הרשת.  
- **Router** — Layer 3, מחליט לפי **IP Address**, מחבר **בין** רשתות (LAN ↔ WAN).

**תשובה 15**  
הראוטר מקבל את החבילה מהמחשב הפנימי (`192.168.1.10:52341`), **מחליף** את כתובת המקור בכתובת ה-Public IP שלו (`82.166.10.5:52400`), **שומר את המיפוי** בטבלת NAT, ושולח את החבילה לאינטרנט.

**תשובה 16**  
- **D** — Discover: הלקוח שולח broadcast "מישהו פה?"  
- **O** — Offer: שרת DHCP מציע כתובת IP  
- **R** — Request: הלקוח מבקש את הכתובת שהוצעה  
- **A** — Acknowledge: השרת מאשר

**תשובה 17**  
- **TCP** — אמין, מאשר קבלה, שומר סדר. שימושים: HTTP, SSH, Email.  
- **UDP** — מהיר, ללא אישור, ייתכן שחבילות יאבדו. שימושים: DNS, Streaming, Gaming.

**תשובה 18**  
1. **SYN** — הלקוח שולח "רוצה להתחבר"  
2. **SYN-ACK** — השרת עונה "אשרתי, גם אני רוצה"  
3. **ACK** — הלקוח מאשר "מחובר"

**תשובה 19**  
1. **DNS Query** — המחשב שואל שרת DNS מהו ה-IP של `www.google.com`.  
2. **DNS Response** — מקבל את כתובת ה-IP (למשל `142.250.185.78`).  
3. **TCP Handshake (SYN→SYN-ACK→ACK)** — המחשב פותח חיבור אמין לאותה כתובת IP על פורט 443.

### חלק ד — Wireshark

**תשובה 20**  
- **Display Filter** — מסנן מה **מוצג** מתוך הקלטה קיימת. כתוב בממשק Wireshark בזמן אמת.  
- **Capture Filter** — מגדיר מה **יוקלט** בכלל (לפני ההקלטה), כתוב בתחביר BPF. חוסך מקום ומשאבים.

**תשובה 21**  
```wireshark
dns and ip.dst == 8.8.8.8
```

**תשובה 22**  
**בעיות ברשת** — חבילות הולכות לאיבוד ו-TCP נאלץ לשלוח אותן שוב. יכול להצביע על כבל פגום, עומס ברשת, או ממשק רשת עם בעיות.

**תשובה 23**  
לחיצה ימנית על חבילת HTTP → **Follow → TCP Stream** — יפתח חלון שמציג את כל השיחה (בקשה + תשובה מלאה).

### חלק ה — Linux

**תשובה 24**  
- **`find`** — מחפש **בזמן אמת** בדיסק, מדויק, אבל איטי יותר.  
- **`locate`** — מחפש ממסד נתונים (**מהיר**), אבל עשוי להיות לא מעודכן (מתעדכן פעם ביום עם `updatedb`).

**תשובה 25**  
`rwxr-xr--`  
- **Owner**: `rwx` — קריאה, כתיבה, הרצה  
- **Group**: `r-x` — קריאה והרצה (לא כתיבה)  
- **Others**: `r--` — קריאה בלבד

**תשובה 26**  
```bash
chmod 755 script.sh
```
`755` = `rwxr-xr-x` — Owner: rwx, Group: r-x, Others: r-x

**תשובה 27**  
מציגה את כל התהליכים הפועלים (`ps aux`) ומסננת (`grep nginx`) רק את אלה שקשורים ל-nginx.

**תשובה 28**  
- `kill <PID>` — שולח אות **SIGTERM** (15) — מבקש מהתהליך לסגור בצורה מסודרת.  
- `kill -9 <PID>` — שולח אות **SIGKILL** — סוגר כפויה, התהליך לא יכול להתנגד.

**תשובה 29**  
הפקודה:
1. `cat /var/log/syslog` — קוראת את קובץ הלוג
2. `| grep "error"` — מסננת רק שורות שמכילות "error"
3. `| wc -l` — סופרת כמה שורות כאלה יש

**הפלט:** מספר שלם — כמות שורות שגיאה ב-syslog.

**תשובה 30**  
שינוי שם הקובץ כך שיתחיל בנקודה:  
```bash
mv file.txt .file.txt
```
ב-Linux, קובץ שמתחיל בנקודה **מוסתר** ולא מוצג ב-`ls` רגיל (מוצג רק עם `ls -a`).
