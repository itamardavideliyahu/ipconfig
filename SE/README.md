# הדגמת מתקפת הנדסה חברתית (Phishing) - לכיתה בלבד

אפליקציית web קטנה המדמה דף התחברות (מותג פיקטיבי "SecureMail") לצורך הדגמה חינוכית
של מתקפת דיוג (phishing) בקורס הנדסה חברתית. כל שם משתמש וסיסמה שיוקלדו בדף ההתחברות
מוצגים בזמן אמת בלוח מרצה, כדי להמחיש כמה קל לאסוף פרטי התחברות בעמוד מזויף.

## ⚠️ כללי שימוש - חשוב

- **לרשת מקומית/כיתתית מבודדת בלבד.** אין לפרוס את זה בשרת/VPS ציבורי או לחשוף
  אותו לאינטרנט הרחב (אין port forwarding בראוטר).
- **קבלו הסכמה מדעת** מהמשתתפים לפני התרגיל, והסבירו (debrief) בסופו.
- **אין להזין כאן פרטי התחברות אמיתיים** לשום שירות אמיתי - רק סיסמאות/שמות
  משתמש פיקטיביים לצורך התרגיל.
- הנתונים נשמרים **בזיכרון בלבד** (לא בקובץ ולא במסד נתונים) ונמחקים אוטומטית
  כשעוצרים את הקונטיינר. יש גם כפתור "מחיקת כל הנתונים" בלוח המרצה.
- דף ההתחברות המדומה מסומן בבאנר אדום "סביבת הדגמה לקורס" כדי שלא ניתן להתבלבל
  עם אתר אמיתי.

## הרצה עם Docker (מומלץ)

```bash
docker compose up -d --build
```

- דף ההתחברות המדומה (להראות/לשלוח למשתתפים): `http://localhost:3000/login.html`
- לוח המרצה (להציג על המקרן): `http://localhost:3000/dashboard.html`

כדי שגם מחשבים/טלפונים אחרים **באותה רשת כיתה** יוכלו לגשת לדף ההתחברות, מצאו
את כתובת ה-IP המקומית של המחשב המארח (למשל `ipconfig` בחלון `IPv4 Address`) וגשו
מהמכשיר האחר לכתובת `http://<IP-מקומי>:3000/login.html`.

לעצירה:

```bash
docker compose down
```

## הרצה ללא Docker (חלופה)

```bash
npm install
npm start
```

## מבנה הפרויקט

- `server.js` - שרת Express + Socket.io, שומר את הנתונים הנקלטים בזיכרון בלבד.
- `public/login.html/.css/.js` - דף ההתחברות המדומה שרואה ה"קורבן" (המתנדב/ת בכיתה).
  לאחר שליחת הטופס מוצג לו/ה מיד הסבר (debrief) שזו הייתה הדגמה.
- `public/dashboard.html/.css/.js` - לוח המרצה, מציג בזמן אמת (WebSocket) את כל
  שמות המשתמש/סיסמאות שהוזנו, עם כפתור למחיקת הנתונים.

## הצעה למבנה השיעור

1. הציגו את לוח המרצה על המקרן (ריק בהתחלה).
2. שלחו למתנדב/ת בכיתה קישור לדף ההתחברות (`/login.html`) - אפשר "לחפות" עליו
   כהודעה מדומה (SMS/מייל) כחלק מהתרגיל.
3. כאשר המתנדב/ת מקליד/ה פרטים ולוחץ/ת "התחברות", הפרטים מופיעים באופן חי על
   המקרן - זה הרגע ה"וואו" של ההדגמה.
4. דונו בכיתה: אילו רמזים היו יכולים לחשוף שזה דף מזויף (כתובת URL, חיבור לא
   מוצפן, שגיאות עיצוב, לחץ/דחיפות בהודעה וכו').
5. בסוף השיעור, לחצו על "מחיקת כל הנתונים" בלוח המרצה.
