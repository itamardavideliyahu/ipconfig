# תחזוקה יומית ב-Windows Server — סקריפטים לתלמידים

## רקע קצר

בסביבת **Windows Server** מנהל מערכת מבצע מדי יום (או לפחות באופן קבוע) בדיקות בסיסיות: האם השרת עולה תקין, האם יש מקום בדיסק, האם שירותים קריטיים רצים, והאם יש בעיות ברשת או ביומן האירועים.

במסמך זה יש שני סקריפטים שעושים **אותה מטרה בגישות שונות**:

| קובץ | שפה | מתי להשתמש |
|------|-----|------------|
| `Daily-Maintenance.bat` | CMD / Batch | היכרות ראשונה, מחשבים ישנים, הרצה בלחיצה כפולה |
| `Daily-Maintenance.ps1` | PowerShell | סביבות מודרניות, דוח מפורט יותר, אוטומציה |

שני הסקריפטים **לא משנים הגדרות** במערכת — רק **קוראים** מידע ושומרים דוח לתיקיית `logs`.

> **הערה:** פלט הסקריפטים באנגלית (מונחי מערכת סטנדרטיים) כדי למנוע בעיות קידוד ב-CMD/PowerShell. ההסבר בעברית נמצא במדריך זה.

---

## מטרות למידה

- להבין מה בודקים בתחזוקה שוטפת של שרת.
- להכיר פקודות Windows נפוצות (`hostname`, `systeminfo`, `wmic`, `sc`, `ipconfig`, `ping`).
- להשוות בין Batch ל-PowerShell באותה משימה.
- ללמוד לשמור לוג (הפניית פלט לקובץ).
- לדעת מתי צריך הרשאות מנהל.

## מבנה התיקייה

```
windows-server/
├── Daily-Maintenance.bat      ← סקריפט CMD

├── Windows-Server-Maintenance.md   ← המדריך הזה
└── logs/                      ← נוצר אוטומטית בהרצה
    └── maintenance_YYYYMMDD_HHMMSS.log
```

## מה הסקריפטים בודקים?

| שלב | מה נבדק | למה זה חשוב |
|-----|---------|-------------|
| 1 | שם שרת, משתמש, מערכת הפעלה, זמן פעילות | לוודא שזה השרת הנכון ושלא אתחלו לאחרונה בלי לדעת |
| 2 | שטח פנוי בדיסקים | דיסק מלא = קריסות ושירותים שנעצרים |
| 3 | שירותים (Event Log, Server, שעון, DNS…) | שירות עצור = תקלה ללקוחות |
| 4 | רשת (Gateway, ping ל-8.8.8.8) | בלי רשת — אין גישה ל-AD, גיבוי, עדכונים |
| 5 | שגיאות ביומן (ב-PS1) / סקירת תהליכים (ב-BAT) | רמזים לבעיה לפני שהמשתמשים מתלוננים |

## הרצת סקריפט ה-Batch

1. פתחו את התיקייה `windows-server`.
2. לחיצה כפולה על `Daily-Maintenance.bat`  
   **או** מ-`CMD`:

```bat
cd /d "C:\נתיב\ל\windows-server"
Daily-Maintenance.bat
```

3. בסיום — בדקו את הקובץ בתיקיית `logs`.

### פקודות עיקריות ב-Batch (ללמידה)

| פקודה | תפקיד |
|--------|--------|
| `@echo off` | לא להציג כל שורת פקודה במסך |
| `chcp 65001` | תמיכה בעברית בחלון |
| `setlocal` / משתנים `%VAR%` | הגדרת נתיבים ושמות קבצים |
| `mkdir` | יצירת תיקיית לוג |
| `call :Log` | פונקציה פשוטה — הדפסה + כתיבה לקובץ |
| `hostname` | שם המחשב |
| `systeminfo` | פרטי מערכת |
| `wmic logicaldisk` | מידע על כוננים |
| `sc query` | סטטוס שירות |
| `ipconfig` / `ping` | רשת |
| `>> קובץ` | הוספת פלט לסוף קובץ (לוג) |

---

## הרצת סקריפט PowerShell

1. פתחו **PowerShell** (מומלץ **כמנהל** לקריאת יומן אירועים מלאה).
2. עברו לתיקייה והריצו:

```powershell
cd "C:\נתיב\ל\windows-server"
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\Daily-Maintenance.ps1
```

אם מופיעה שגיאת Execution Policy — הפקודה `Bypass` למעלה חלה **רק על החלון הנוכחי** (בטוח לתרגול).

### פקודות עיקריות ב-PowerShell (ללמידה)

| פקודה | תפקיד |
|--------|--------|
| `$PSScriptRoot` | תיקיית הסקריפט (נתיב יחסי ללוג) |
| `Get-CimInstance Win32_OperatingSystem` | מידע OS וזמן אתחול |
| `Get-CimInstance Win32_LogicalDisk` | דיסקים + חישוב אחוזים |
| `Get-Service` | סטטוס שירות |
| `Get-NetRoute` | מציאת Default Gateway |
| `Test-Connection` | ping מודרני |
| `Get-WinEvent` | שגיאות מיומן System (24 שעות) |
| `Add-Content` | כתיבה לקובץ לוג |

## השוואה: Batch מול PowerShell

```
┌─────────────────────┬──────────────────────┬──────────────────────┐
│                     │ Batch (.bat)         │ PowerShell (.ps1)    │
├─────────────────────┼──────────────────────┼──────────────────────┤
│ קל ללמידה           │ כן — פקודות ישירות  │ דורש הבנת אובייקטים  │
│ חישובי דיסק         │ גולמי (בתים)         │ GB ואחוזים אוטומטי  │
│ יומן אירועים        │ לא בגרסה זו          │ כן (5 אחרונות)       │
│ הרשאות              │ בדרך כלל משתמש רגיל │ מנהל ל-Event Log     │
│ אוטומציה (Task)     │ אפשרי               │ מומלץ               │
└─────────────────────┴──────────────────────┴──────────────────────┘
```

## תרגילים לכיתה

### תרגיל 1 — הרצה והשוואה
הריצו את שני הסקריפטים על אותו מחשב. השוו: מה מופיע רק ב-PS1? מה נוח יותר לקרוא?

### תרגיל 2 — הוספת שירות
ב-Batch: הוסיפו לרשימה `SVCLIST` את השירות `BITS`.  
ב-PS1: הוסיפו `"BITS"` למערך `$services`.  
הסבירו במשפט מה השירות עושה (חיפוש באינטרנט / `Get-Service BITS`).

### תרגיל 3 — סף אזהרה לדיסק
ב-PS1 שנהו את `90` ל-`80` — תראו אזהרה מוקדם יותר. למה מנהל בוחר סף נמוך בשרת ייצור?

### תרגיל 4 — תזמון (מתקדם)
צרו **Task Scheduler** להרצת `Daily-Maintenance.ps1` כל יום ב-07:00.  
רמז: פעולה `powershell.exe` עם ארגומנטים `-File "נתיב\Daily-Maintenance.ps1"`.

## חוקי בטיחות בכיתה

1. **רק קריאה** — הסקריפטים לא מוחקים קבצים ולא עוצרים שירותים.
2. על **שרת אמיתי בייצור** — קודם בודקים בסביבת מעבדה / VM.
3. לא משתפים סיסמאות או מידע רגיש בלוגים לפני שליחה.
4. הרצה כמנהל — רק כשצריך, ורק בהדרכת המורה.

## פתרון בעיות נפוצות

| בעיה | פתרון |
|------|--------|
| `cannot be loaded because running scripts is disabled` | `Set-ExecutionPolicy -Scope Process Bypass` |
| יומן אירועים ריק / שגיאה ב-PS1 | הריצו PowerShell **כמנהל** |
| עברית משובשת ב-CMD | ודאו ש-`chcp 65001` רץ; נסו גופן Consolas |
| `wmic` לא מזוהה | ב-Server 2025+ ייתכן ש-wmic הוסר — השתמשו ב-PS1 לדיסקים |
| אין ping ל-8.8.8.8 | ייתכן חומת אש — זה ממילא מידע חשוב לדוח |

## סיכום

תחזוקה יומית טובה היא **עקבית ופשוטה**: אותן בדיקות, דוח ברור, תיעוד בלוג.  
Batch מלמד את הבסיס; PowerShell מאפשר דוח עשיר ואוטומציה — שני הכלים שימושיים למנהל Windows Server מתחיל.
