# 🌐 יסודות הרשת — מדריך למתחילים

---

## 1. IP Address — כתובת IP

כתובת IP היא **כתובת ייחודית** שמזהה כל מכשיר ברשת, בדיוק כמו כתובת בית.

פורמט: `192.168.1.10` — 4 מספרים בין 0–255, מופרדים בנקודות.

---

## 2. Public IP — כתובת IP ציבורית

| מאפיין | פרטים |
|--------|--------|
| **מה זה?** | כתובת שנראית על גבי האינטרנט |
| **מי מקצה?** | ספק האינטרנט (ISP) |
| **ייחודיות** | ייחודית בעולם כולו |
| **דוגמה** | `82.166.10.5` |

> **בקצרה:** זו "כתובת הבית" שלך מול העולם — כולם באינטרנט רואים אותה.

---

## 3. Private IP — כתובת IP פרטית

| מאפיין | פרטים |
|--------|--------|
| **מה זה?** | כתובת פנימית בתוך הרשת הביתית/ארגונית |
| **מי מקצה?** | ה-Router / DHCP |
| **ייחודיות** | ייחודית רק בתוך הרשת הפנימית |
| **טווחים שמורים** | `10.x.x.x` / `172.16–31.x.x` / `192.168.x.x` |

> **בקצרה:** כמו מספרי חדרים בבניין — בתוך הבניין ברור, מבחוץ לא רואים.

### ההבדל הוויזואלי:

```
האינטרנט
    |
[Public IP: 82.166.10.5]
    |
  Router
  /    \
PC1    PC2
192.168.1.2   192.168.1.3
(Private IP)  (Private IP)
```

---

## 4. Subnet Mask — מסכת רשת

**מה זה עושה?**
מגדיר איזה חלק מהכתובת הוא **הרשת** ואיזה חלק הוא **המכשיר**.

| דוגמה | משמעות |
|-------|--------|
| `255.255.255.0` | 24 ביטים לרשת, 8 ביטים למכשירים (עד 254 מכשירים) |
| `255.255.0.0` | 16 ביטים לרשת, 16 ביטים למכשירים |

**דוגמה מעשית:**
```
IP:           192.168.1.10
Subnet Mask:  255.255.255.0
              ─────────────
רשת:          192.168.1.___
מכשיר:                   .10
```

> **בקצרה:** Subnet Mask אומר לרשת "מי שייך לאותה שכונה ומי לא".

---

## 5. Default Gateway — שער ברירת מחדל

**מה זה?** הכתובת של ה-**Router** — הדלת שדרכה יוצאים לאינטרנט.

```
PC שלך  ──→  Default Gateway (Router)  ──→  האינטרנט
192.168.1.10        192.168.1.1
```

- כשאתה פותח אתר → המחשב שולח את הבקשה ל-Gateway
- ה-Gateway מעביר החוצה לאינטרנט
- התשובה חוזרת דרכו אליך

> **בקצרה:** Default Gateway = ה-Router שלך = הדלת לאינטרנט.

---

## 6. DNS — Domain Name System

**הבעיה:** לזכור `142.250.185.78` קשה. לזכור `google.com` קל.

**הפתרון:** DNS הוא "ספר טלפונים של האינטרנט" — ממיר שמות לכתובות IP.

```
אתה כותב:    google.com
     ↓
DNS שואל:    מה ה-IP של google.com?
     ↓
DNS עונה:    142.250.185.78
     ↓
הדפדפן מתחבר לאותה כתובת IP
```

**שרתי DNS נפוצים:**
| ספק | כתובת |
|-----|--------|
| Google | `8.8.8.8` |
| Cloudflare | `1.1.1.1` |
| Router ביתי | `192.168.1.1` |

> **בקצרה:** DNS = תרגום שם → IP.

---

## 7. DHCP — Dynamic Host Configuration Protocol

**הבעיה:** להגדיר ידנית IP לכל מכשיר ברשת זה סיוט.

**הפתרון:** DHCP מחלק כתובות IP **אוטומטית** לכל מכשיר שמתחבר.

```
מחשב חדש מתחבר לרשת
        ↓
שולח בקשה: "מישהו פה? צריך IP!"
        ↓
DHCP Server (בד"כ ה-Router) עונה:
"קח את הכתובת 192.168.1.25,
 ה-Gateway שלך: 192.168.1.1,
 ה-DNS שלך: 8.8.8.8"
        ↓
המחשב מוגדר אוטומטית ✅
```

> **בקצרה:** DHCP = רובוט שמגדיר את הרשת בשבילך אוטומטית.

## סיכום בטבלה

| מונח | תפקיד | דוגמה |
|------|--------|--------|
| **Public IP** | זיהוי ברשת האינטרנט | `82.166.10.5` |
| **Private IP** | זיהוי בתוך הרשת הפנימית | `192.168.1.10` |
| **Subnet Mask** | מגדיר גבולות הרשת | `255.255.255.0` |
| **Default Gateway** | הדלת לאינטרנט (Router) | `192.168.1.1` |
| **DNS** | מתרגם שמות לכתובות IP | `8.8.8.8` |
| **DHCP** | מחלק הגדרות רשת אוטומטית | שרות ב-Router |

## בדיקה מהירה — פקודות שימושיות

```bash
# Windows — הצג הגדרות רשת
ipconfig /all

# Windows — בדוק DNS
nslookup google.com

# Windows — בדוק חיבור
ping 8.8.8.8
```
