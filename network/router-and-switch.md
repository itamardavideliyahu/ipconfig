# 🧭 Router ו-Switch — מדריך למצגת (קורס תקשורת מחשבים)

---

## מטרות למידה

בסיום השיעור התלמיד/ה יוכל/י:

- להסביר מה תפקיד ה-**Router** ומה תפקיד ה-**Switch**
- לזהות באיזו **שכבת OSI** כל רכיב פועל (Layer 2 מול Layer 3)
- לתאר **תהליך מלא** של גלישה לאינטרנט — מהמחשב, דרך הסוויץ', דרך הראוטר, וחזרה
- להבדיל בין תעבורה **פנימית** (בתוך ה-LAN) לתעבורה **חיצונית** (ל-WAN / אינטרנט)

---

## רקע: שתי שכבות — שני סוגי כתובות

| שכבה | שם | כתובת שמשתמשים בה | דוגמה |
|------|-----|-------------------|--------|
| **Layer 2** | Data Link | **MAC Address** | `AA:BB:CC:DD:EE:FF` |
| **Layer 3** | Network | **IP Address** | `192.168.1.10` |

> **רעיון מפתח:** הסוויץ' "חושב" ב-MAC. הראוטר "חושב" ב-IP.

---

## 🧭 מה זה Router (ראוטר)?

הראוטר הוא **המוח של הרשת** — הרכיב שמחבר בין **רשתות שונות**.

לדוגמה: בין הרשת הביתית/הארגונית שלך (`LAN`) לבין האינטרנט (`WAN`).

### אנלוגיה פשוטה

| רכיב | תפקיד |
|------|--------|
| **Switch** | מסדרן בתוך הבניין — מעביר מכתבים בין דירות |
| **Router** | דלפק הכניסה + שומר — מחליט מה יוצא החוצה ומה חוזר פנימה |

### תפקידים מרכזיים

| תפקיד | הסבר קצר |
|--------|-----------|
| **ניתוב (Routing)** | מחליט לאיזו רשת לשלוח כל חבילה — לפי כתובת IP |
| **DHCP** | מחלק כתובות IP אוטומטית למכשירים ברשת |
| **Firewall** | חוסם או מאפשר תעבורה לפי כללים |
| **NAT** | מתרגם כתובות IP פנימיות (Private) לכתובת ציבורית (Public) |
| **Default Gateway** | ה"דלת" שדרכה מכשירים יוצאים לאינטרנט |

### איפה הוא נמצא?

```
                    האינטרנט (WAN)
                          |
                    ┌───────────┐
                    │  ROUTER   │  ← תמיד בקצה הרשת, ליד ספק האינטרנט
                    └─────┬─────┘
                          │
                    הרשת הפנימית (LAN)
```

> **בקצרה:** הראוטר = **מנהל תעבורה בין רשתות**, נותן אינטרנט, מחלק IP, ומאבטח.

---

## 🖧 מה זה Switch (סוויץ')?

הסוויץ' הוא **מרכזיית החיבורים הפנימית** — מחבר מכשירים **בתוך אותה רשת**.

מחשבים, מצלמות, שרתים, מדפסות, נקודות גישה (Access Points) ועוד.

### תפקידים מרכזיים

| תפקיד | הסבר קצר |
|--------|-----------|
| **העברת תעבורה (Switching)** | מעביר חבילות בין פורטים — לפי כתובת MAC |
| **MAC Learning** | לומד איזה MAC מחובר לאיזה פורט, ושולח רק ליעד הנכון |
| **VLANs** | (בסוויץ' מנוהל) מחלק רשת פיזית אחת לרשתות לוגיות נפרדות |
| **Full Duplex** | כל פורט יכול לשלוח ולקבל במקביל |

### מה הסוויץ' **לא** עושה?

- ❌ לא יודע "לצאת לאינטרנט" בעצמו
- ❌ לא מבצע NAT
- ❌ לא מנתב בין רשתות IP שונות (זה תפקיד הראוטר)

```
        ┌─────────┐
   PC ──┤         ├── Printer
        │ SWITCH  ├── Camera
   PC ──┤         ├── Server
        └────┬────┘
             │
          Router
```

> **בקצרה:** הסוויץ' = **מחבר מכשירים בתוך הרשת הפנימית** ומנהל תעבורה ביניהם.

---

## 🔗 ההבדל העיקרי — השוואה

| רכיב | תפקיד | שכבה (OSI) | מה הוא עושה |
|------|--------|------------|-------------|
| **Router** | מחבר **בין רשתות** | Layer 3 | שולח תעבורה בין רשתות שונות (`LAN ↔ WAN`) |
| **Switch** | מחבר **בתוך אותה רשת** | Layer 2 | מפיץ תעבורה בין מכשירים באותה רשת (`LAN`) |

### טבלת השוואה מורחבת

| מאפיין | Router | Switch |
|--------|--------|--------|
| **כתובת שמזהה מכשירים** | IP | MAC |
| **טבלת החלטות** | Routing Table | MAC Address Table |
| **חיבור לאינטרנט** | כן | לא (ישירות) |
| **DHCP / NAT / Firewall** | בדרך כלל כן | לא |
| **מיקום ברשת** | בקצה — ליד ה-ISP | במרכז — מחבר את כל המכשירים |

```
                                  │

       ┌──────▼──────┐     ┌──────▼──────┐     ┌──────▼──────┐
       │   SWITCH    │     │  Wi-Fi AP   │     │   (פורט)    │
```

| מכשיר | Private IP | MAC (דוגמה) |

| PC-1 | `192.168.1.10` | `AA:BB:CC:11:22:33` |
| PC-2 | `192.168.1.11` | `AA:BB:CC:44:55:66` |

## 🔄 איך Router ו-Switch עובדים יחד?

### תרחיש: מחשב רוצה לגלוש ל-`google.com`

#### שלב 1 — המחשב שולח בקשה

```
PC-1 (192.168.1.10)  →  "אני רוצה google.com"
```

- המחשב בודק: היעד **לא** באותה רשת מקומית
- לכן שולח את החבילה ל-**Default Gateway** (`192.168.1.1` = הראוטר)
- ב-Layer 2: כתובת היעד = **MAC של הראוטר**

#### שלב 2 — הסוויץ' מעביר לראוטר

```
PC-1 ──► SWITCH ──► ROUTER
         (MAC table:
          .10 → Port 1
          Router → Port 5)
```

- הסוויץ' מקבל חבילה בפורט 1
- בודק: יעד MAC = הראוטר
- מעביר **רק** לפורט שמחובר אליו הראוטר (לא לכל המכשירים!)

#### שלב 3 — הראוטר מעבד ושולח החוצה

```
ROUTER:
  1. בודק IP יעד → google.com (מחוץ ל-LAN)
  2. שואל DNS → מקבל IP ציבורי
  3. מבצע NAT → 192.168.1.10  ←→  Public IP
  4. שולח החוצה דרך WAN ל-ISP
```

#### שלב 4 — התשובה חוזרת מהאינטרנט

```
google.com ──► ISP ──► ROUTER (WAN)
```

- הראוטר מזהה: "זו תשובה לבקשה ש-PC-1 שלח"
- מבצע **NAT הפוך** — מחזיר ל-IP הפנימי `192.168.1.10`

#### שלב 5 — הראוטר מחזיר לסוויץ'

```
ROUTER ──► SWITCH
יעד: MAC של PC-1
```

#### שלב 6 — הסוויץ' מעביר למחשב הנכון

```
SWITCH ──► PC-1 (Port 1)
```

- הסוויץ' יודע מטבלת ה-MAC ש-`PC-1` מחובר לפורט 1
- מעביר **רק** אליו — לא לשאר המכשירים

```
     │              │               ├──────────────►│
     │              │               │  ④ תשובה      │
     │              │               │◄──────────────┤
     │              │  ⑤ forward    │               │
     │              │◄──────────────┤               │
     │  ⑥ למחשב     │               │               │
     │◄─────────────┤               │               │
```

## 🔄 תרחיש נוסף — תעבורה **פנימית** (בלי אינטרנט)

**PC-1** (`192.168.1.10`) שולח קובץ ל-**PC-2** (`192.168.1.11`):

```
PC-1 ──► SWITCH ──► PC-2
```

| שלב | מה קורה |
|-----|---------|
| 1 | PC-1 רואה: PC-2 **באותה רשת** — לא צריך Router |
| 2 | PC-1 שולח ישירות ל-MAC של PC-2 |
| 3 | הסוויץ' מעביר מפורט 1 לפורט 2 |
| 4 | **הראוטר לא מעורב בכלל** ✅ |

> **כלל אצבע:** תעבורה **בין מכשירים באותה רשת** = Switch בלבד.  
> תעבורה **שיוצאת מהרשת** = חייבת לעבור דרך Router.

## ⚠️ בלבולים נפוצים — שווה להדגיש בכיתה

| שאלה | תשובה |
|------|--------|
| **האם Router = Wi-Fi?** | לא בהכרח. Wi-Fi הוא **שירות אלחוטי** — לעיתים מובנה בראוטר ביתי, אבל זה לא אותו דבר |
| **מה זה Modem?** | ממיר אות מהקו (סיב / ADSL / כבל) ל-Ethernet. לעיתים Modem + Router = **מכשיר אחד** |
| **ראוטר ביתי "All-in-One"?** | מכשיר אחד שמשלב: Modem + Router + Switch (4 פורטים) + Wi-Fi + DHCP |
| **Hub vs Switch?** | Hub (ישן) משדר לכולם. Switch חכם — שולח רק ליעד הנכון |
| **Layer 3 Switch?** | סוויץ' מתקדם שיודע גם לנתב — נפוץ בארגונים, מעבר לחומר בסיסי |

## 🎯 סיכום — שורה אחת לכל רכיב

| רכיב | במשפט אחד |
|------|-----------|
| **Router** | מנהל תעבורה **בין רשתות**, נותן אינטרנט, מחלק IP, מאבטח (NAT, Firewall) |
| **Switch** | מחבר מכשירים **בתוך הרשת הפנימית** ומנהל תעבורה ביניהם לפי MAC |
| **יחד** | Switch = תנועה פנימית · Router = כל מה שיוצא (או נכנס) מהרשת |

## ✅ בדיקה עצמית — שאלות לתלמידים

1. באיזו שכבת OSI פועל Switch? ו-Router?
2. מחשב עם IP `192.168.1.50` רוצה לגלוש לאינטרנט — לאיזה כתובת IP הוא שולח את החבילה?
3. PC-1 שולח קובץ ל-PC-2 באותה רשת — האם ה-Router מעורב?
4. מה ההבדל בין כתובת MAC לכתובת IP?
5. מה תפקיד NAT ולמה הוא נחוץ?

<details>
<summary>📋 תשובות (למדריך)</summary>

1. Switch = Layer 2, Router = Layer 3  
2. ל-Default Gateway — בדרך כלל `192.168.1.1` (כתובת ה-Router)  
3. לא — התעבורה נשארת בתוך ה-LAN  
4. MAC = זיהוי כרטיס רשת (Layer 2), IP = כתובת לוגית (Layer 3)  
5. NAT מתרגם IP פנימי לציבורי — מאפשר לכל המכשירים ברשת לגלוש עם IP ציבורי אחד  

</details>
